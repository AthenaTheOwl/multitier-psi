# the supplier dictionary belongs in the threat model

method update: october 18, 2026. proposed experiments below are not reported as executed results.

the protocol operates on canonical supplier identifiers prepared before intersection. privacy therefore depends on the preprocessing and identifier universe as well as the cryptographic exchange. a party with a small guessed supplier dictionary can test hypotheses across repeated sessions (the single-session full sweep is now rejected by `assert_leakage_boundary`; see the dictionary attack section of `docs/security-disclosure.md`); aliases or inconsistent tier traversal can also create false matches or false nonmatches without any protocol failure. a supplier with no dictionary match is dropped before the single-source count, so a component's remaining supplier can be reported as single-source and enter the intersection.

the local `show` demonstration prints both fixture parties' unique suppliers to explain the scenario. that local demonstration has broader visibility than the dh_based result, which lets a party learn only the shared supplier ids and the intersection size; the session record `mtpsi run` prints carries the intersection size and transcript hash only. keep those output contracts explicit when describing leakage. a schema allowlist or deterministic transcript test cannot establish a cryptographic security proof.

a bounded next test uses two aliases for one synthetic supplier, an intentionally ambiguous alias, a second source spelled with an alias the dictionary lacks, and a tier cycle. canonicalization (`canonicalize_graph` in `src/mtpsi/party.py`) today keeps the last alias on a collision and silently skips unmapped names. it should produce a reviewable mapping, decline ambiguity, report unmapped suppliers instead of dropping them from the single-source count, and terminate traversal deterministically. a separate session-level test should record repeated-query visibility and dictionary version. production claims require an audited construction and an explicit adversary model. no real supplier list or private drive material belongs in the fixtures.
